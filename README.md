# Просмотр USB-камеры и двух MaixSense A010

Окно показывает USB-камеру во всю ширину сверху, а две цветные карты глубины Sipeed MaixSense A010 — в один ряд снизу. Каждая панель сохраняет пропорции кадра при изменении размеров окна.

## Установка и запуск

Понадобятся Python 3.10 или новее, Tk и графический сеанс. Запускайте приложение на компьютере, к которому подключены устройства.

### Windows

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

### Linux и macOS

В Debian/Ubuntu установите Tk и поддержку виртуальных окружений командой `sudo apt install python3-tk python3-venv`. На macOS используйте сборку Python с Tk. Проверить Tk можно командой `python3 -m tkinter`.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

## Устройства и управление

1. Подключите камеру и оба A010 USB-кабелями с передачей данных. Если подключили их после запуска, нажмите **Обновить устройства**.
2. В правом верхнем углу панели **Камера** выберите её номер. В Linux приложение проверяет индексы из `/dev/video*`. В Windows и macOS оно проверяет индексы OpenCV от 0 до 9.
3. В панелях **ToF 1** и **ToF 2** выберите разные порты A010. В Windows это, например, `COM3`, в Linux — `/dev/ttyUSB0`. В списке видны все обнаруженные последовательные порты. Чтобы определить, какой порт относится к каждому A010, подключите датчики по одному и обновите список после каждого подключения.
4. Кнопка **↻ 90°** поворачивает кадр выбранной панели на 90° по часовой стрелке. Пункт **Не выбрано** отключает поток на этой панели.

Если устройство не появилось, проверьте кабель, драйвер и права доступа. В Windows номер порта можно посмотреть в диспетчере устройств. В Debian/Ubuntu для доступа к последовательному порту обычно нужно членство в группе `dialout` и повторный вход в систему после добавления. Закройте ComTool и другие приложения, которые используют камеру или порты. После переподключения обновите список и снова выберите устройство.

A010 читается на скорости 921600 бод. Поддерживаются 8-битные кадры 25×25, 50×50 и 100×100. Если после открытия порта датчик не передаёт кадры, приложение отправляет команды Sipeed для включения ISP и вывода по USB с сохранением изображения на встроенном дисплее. Цвета показывают значения глубины, переданные датчиком. Их соответствие миллиметрам зависит от настройки `UNIT`.
